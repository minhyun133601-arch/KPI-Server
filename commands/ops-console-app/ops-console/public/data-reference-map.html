데이터 참조 경로

현재 구현된 입력 화면이 어떤 런타임, API, DB 레코드, 파일 저장소, 권한키를 거쳐 저장되는지 정리합니다.

axis 1 JSON 본문 저장

대부분의 화면 본문은 PostgreSQL app_module_records의 module_key + record_key로 저장됩니다.

axis 2 파일/이미지 저장

첨부 메타는 app_documents, 실제 바이트는 KPI_STORAGE_ROOT/files 아래 도메인별 폴더로 갑니다.

axis 3 전용 구조 테이블

생산일보처럼 행 단위 집계가 필요한 영역은 util_production_daily_* 전용 테이블을 씁니다.

shared write model 같은 권한키를 가진 사용자는 같은 저장내역을 수정합니다

app_module_records는 개인 PC 저장이 아니라 서버 공용 DB 레코드입니다. 로그인 사용자가 해당 permission_key의 write 권한을 받으면 같은 record_key의 저장내역을 읽고 수정할 수 있습니다.
