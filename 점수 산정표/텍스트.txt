Phase 0 — 상수 & 데이터 모델
KPI 점수 산정 도구의 데이터 모델을 정의해라. ■ scoreScale (불변 상수) S=1.10 (110점), A=1.00 (100점), B=0.85 (85점), C=0.70 (70점), D=0.55 (55점) ■ metricConfig 객체 { id: string, name: string, // KPI명 (사용자 입력) weight: number|null, // 비중 % (사용자 입력) unitType: string, // "건수"|"개"|"횟수"|"일"|"%"|"백만원"|"점" 등 (사용자 입력) integerMetric: boolean, // unitType ∈ ["건수","개","횟수","일"] → true, 나머지 false (자동) direction: "up"|"down", // up=클수록좋음, down=작을수록좋음 (사용자 선택) target: number|null, // 목표 (사용자 입력) floor: number|null, // 하한 (사용자 입력) actual: number|null // 예상 실적 (사용자 입력) } ■ section 구조 { label: string, // "1분기"|"상반기"|"1~3분기"|"연간" metrics: metricConfig[] // 최대 6개 KPI 행 } ■ direction 규칙 엑셀에서는 수식 패턴(부등호 방향)으로 암묵적 구분. JS에서는 사용자가 ↑up / ↓down 명시 선택.
Phase 1 — 구간 경계값 생성 (buildThresholds)
목표(target)와 하한(floor)으로 S/A/B/C/D 5개 구간 경계값을 생성하는 함수 buildThresholds(metric)를 만들어라. ■ 입력: metricConfig 1개 ■ 출력: { S: number, A: number, B: number, C: number, D: number } ■ 로직: 1) direction="up" (상향식 — 클수록 좋음): S = target × 1.10 A = target D = floor B = ((A − D) / 3) × 2 + D C = ((A − D) / 3) + D 2) direction="down" (하향식 — 작을수록 좋음): S = target − (target × (1.10 − 1.00)) 즉 target × 0.90 ★ 단 target=0이면 S=0 A = target D = floor B = ((A − D) / 3) × 2 + D C = ((A − D) / 3) + D 3) 정수형(integerMetric=true) 반올림 규칙: - 상향식 S등급: ROUNDUP - 상향식 B등급: ROUNDDOWN - 상향식 C등급: ROUNDDOWN - 하향식 S등급: ROUNDDOWN - 하향식 B등급: ROUNDDOWN - 하향식 C등급: ROUNDUP ← 엑셀 원본 quirk - A, D는 반올림 없음 (원본값 그대로) 4) target=null 또는 floor=null → 전부 null ■ 회귀 테스트 (엑셀 K~O열 값과 정확히 일치해야 함): ┌─────────────────────┬───────┬─────┬───┬───┬──────┬──────┬──────┐ │ KPI │ dir │ 단위 │ 목표│ 하한│ S │ A │ B │ C │ D │ ├─────────────────────┼───────┼─────┼───┼───┼──────┼──────┼──────┤ │ 설비 가동률 증대 │ down │ 건수│ 0│1.25│ 0 │ 0 │ 0 │ 1 │ 1.25 │ │ 자체 정비 비용 절감 │ up │ 건수│ 2│ 0 │ 3 │ 2 │ 1 │ 0 │ 0 │ │ 년간 투자 계획 이행률│ up │ % │ 25│ 20 │ 27.5 │ 25 │23.3333│21.6667│ 20 │ │ 건조 배기 가스비 절감│ up │백만원│5.75│5.5│6.325 │5.75 │5.6667 │5.5833 │ 5.5 │ │ 선제적 법규 준수 │ up │ 점 │ 0│ 0 │ 0 │ 0 │ 0 │ 0 │ 0 │ └─────────────────────┴───────┴─────┴───┴───┴──────┴──────┴──────┘ ★ 소수점 정밀도: B,C등급은 무한소수 가능 (23.333333..., 21.666666..., 5.666666..., 5.583333...) → JS에서 float 그대로 유지, 표시만 소수점 1~3자리.
Phase 2 — 달성률 (calcAchievement)
실적 대비 목표 달성률을 계산하는 함수 calcAchievement(metric)를 만들어라. ■ 입력: metric (target, actual, direction) ■ 출력: { ratio: number|null, status: "ok"|"no_input"|"zero_target" } ■ 로직: actual = null/undefined/"" → { ratio: null, status: "no_input" } direction="up": target ≠ 0 → ratio = actual / target target = 0 → { ratio: null, status: "zero_target" } direction="down": target ≠ 0 → ratio = 1 − (actual − target) / target target = 0 → { ratio: null, status: "zero_target" } ■ 회귀 테스트 (엑셀 Q열 값): ┌─────────────────────┬──────┬──────┬───────┬──────────────────────────────┐ │ KPI │ 목표 │ 실적 │ Q열값 │ JS 기대값 │ ├─────────────────────┼──────┼──────┼───────┼──────────────────────────────┤ │ 설비 가동률 증대 │ 0 │ 2 │ "" 빈칸│ { ratio:null, status:"zero_target" } │ │ 자체 정비 비용 절감 │ 2 │ 2 │ 1.0 │ { ratio:1.0, status:"ok" } │ │ 년간 투자 계획 이행률│ 25 │ 30 │ 1.2 │ { ratio:1.2, status:"ok" } │ │ 건조 배기 가스비 절감│ 5.75 │ 0 │ 0.0 │ { ratio:0.0, status:"ok" } │ │ 선제적 법규 준수 │ 0 │ 0 │ "" 빈칸│ { ratio:null, status:"zero_target" } │ └─────────────────────┴──────┴──────┴───────┴──────────────────────────────┘ ★ Q열은 R열(점수)에서 참조하지 않음 → 표시 전용. 엑셀에서 빈칸인 곳을 JS에서는 status로 명시.
Phase 3 — 득점율 보간 (calcScore) ← 핵심
실적이 어느 구간에 속하는지 판정하고 선형 보간으로 득점율을 계산하는 함수 calcScore(metric, thresholds)를 만들어라. ■ 입력: metric + thresholds (Phase 1 결과) ■ 출력: { scoreRate: number, // 0 ~ 1.10 matchedBand: "S"|"A-S"|"B-A"|"C-B"|"D-C"|"below"|null, breakdown: string // 근거 설명 } ■ 로직 (direction="up", 클수록 좋음): actual = null → scoreRate=0, matchedBand=null actual >= S → 1.10 (S등급) A <= actual < S → 보간: 1.00 + (1 − (S−actual)/(S−A)) × (1.10−1.00) B <= actual < A → 보간: 0.85 + (1 − (A−actual)/(A−B)) × (1.00−0.85) C <= actual < B → 보간: 0.70 + (1 − (B−actual)/(B−C)) × (0.85−0.70) D <= actual < C → 보간: 0.55 + (1 − (C−actual)/(C−D)) × (0.70−0.55) actual < D: floor > 0 → 0.55 × actual / floor floor = 0 → 0.55 ■ 로직 (direction="down", 작을수록 좋음): actual = null → scoreRate=0, matchedBand=null actual <= S → 1.10 (S등급) S < actual <= A → 보간: 1.00 + (A−actual)/(A−S) × (1.10−1.00) A < actual <= B → 보간: 0.85 + (B−actual)/(B−A) × (1.00−0.85) B < actual <= C → 보간: 0.70 + (C−actual)/(C−B) × (0.85−0.70) C < actual <= D → 보간: 0.55 + (D−actual)/(D−C) × (0.70−0.55) actual > D → 0.55 ■ 구간폭=0 방어: S=A이면 S등급 판정만 (actual<=S → 1.10, 아니면 다음 구간) A=B=C=D=0일 때 → actual<=0이면 1.10, actual>0이면 0.55 ■ 회귀 테스트 (엑셀 R열, U~Y열 값과 정확히 일치): ┌─────────────────────┬──────┬──────┬────────┬────────┬──────────────────────────┐ │ KPI │ dir │ 실적 │ R(득점율)│ 판정구간│ U │ V │ W │ X │ Y │ ├─────────────────────┼──────┼──────┼────────┼────────┼──────┼──────┼──────┼──────┼──────┤ │ 설비 가동률 증대 │ down │ 2 │ 0.55 │ D초과 │ "" │ "" │ "" │ "" │ 0.55 │ │ 자체 정비 비용 절감 │ up │ 2 │ 1.00 │ A정확히│ "" │ 1.00 │ "" │ "" │ "" │ │ 년간 투자 계획 이행률│ up │ 30 │ 1.10 │ S이상 │ 1.10 │ "" │ "" │ "" │ "" │ │ 건조 배기 가스비 절감│ up │ 0 │ 0.55 │ D미만 │ "" │ "" │ "" │ "" │ 0.55 │ │ 선제적 법규 준수 │ up │ 0 │ 1.10 │ S이상 │ 1.10 │ "" │ "" │ "" │ "" │ └─────────────────────┴──────┴──────┴────────┴────────┴──────┴──────┴──────┴──────┴──────┘ ★ 주의: - "설비 가동률 증대": actual=2 > D=1.25 → 하향식이므로 D초과 = 최저 0.55 - "자체 정비 비용 절감": actual=2, A=2 → 정확히 A등급 경계 = 1.00 (V열에 1.00 표시 = AND(I8>=L8, I8<K8) → AND(2>=2, 2<3) → true) - "건조 배기 가스비 절감": actual=0 < D=5.5 → D미만 엑셀: IF(I10>$H10, O$6*I10/H10, O$6) → 0>5.5 거짓 → 0.55 - "선제적 법규 준수": actual=0, S=0 → 0>=0 → S등급 1.10
Phase 4 — 가중 점수 & 총점
가중 점수와 섹션 합산 함수를 만들어라. ■ calcWeightedScore(scoreRate, weight): return scoreRate × weight ■ sumSection(metrics[]): return round(sum(각 weightedScore), 1) ← 소수점 1자리 반올림 ■ validateSection(metrics[]): weights 합계가 100이 아니면 warning 반환 (엑셀은 1분기만 검증 → JS는 전체 섹션) ■ 회귀 테스트 (엑셀 S열, Z열): ┌─────────────────────┬────────┬──────┬──────────────┐ │ KPI │ 득점율 │ 비중 │ S열(가중점수) │ ├─────────────────────┼────────┼──────┼──────────────┤ │ 설비 가동률 증대 │ 0.55 │ 20 │ 11.0 │ │ 자체 정비 비용 절감 │ 1.00 │ 30 │ 30.0 │ │ 년간 투자 계획 이행률│ 1.10 │ 20 │ 22.0 │ │ 건조 배기 가스비 절감│ 0.55 │ 20 │ 11.0 │ │ 선제적 법규 준수 │ 1.10 │ 10 │ 11.0 │ ├─────────────────────┼────────┼──────┼──────────────┤ │ 비중 합계 │ │ 100 │ │ │ Z7 (1분기 총점) │ │ │ 85.0 │ └─────────────────────┴────────┴──────┴──────────────┘ 계산 검증: ROUND(11+30+22+11+11, 1) = 85.0 ✓
Phase 5 — 입력 검증 (validateMetric)
입력값 유효성을 사전 검증하는 함수 validateMetric(metric)을 만들어라. (★ 엑셀에는 이 기능 없음 — 완전 신규) ■ 검증 규칙: 1) weight = null/음수/100초과 → error 2) target = null인데 actual ≠ null → warning "목표 미설정" 3) floor = null인데 target ≠ null → warning "하한 미설정" 4) direction="up"인데 floor > target → warning "하한이 목표보다 큼" 5) direction="down"인데 floor < target → warning "하한이 목표보다 작음" 6) actual < 0 → warning "음수 실적" 7) integerMetric=true인데 actual이 소수 → warning "정수형 KPI에 소수 입력" 8) target=floor (구간폭=0) → warning "목표와 하한이 같음 — B/C 보간 불가" ■ 출력: { valid: boolean, errors: string[], warnings: string[] }
Phase 6 — UI (HTML + CSS + 인터랙션)
위 로직을 시각적으로 표현하는 단일 HTML 파일을 만들어라. ■ 레이아웃: 1) 상단: 팀명 입력 필드, 분기 탭 4개 (1분기/상반기/1~3분기/연간) 2) 메인 테이블 (분기별): 입력 열 (editable): KPI명 | 비중(%) | 단위 | 방향(↑↓ 드롭다운) | 목표 | 하한 | 예상실적 자동계산 열 (readonly): S | A | B | C | D | 달성률 | 득점율 | 구간 | 가중점수 3) 하단: 비중합계 표시 + 섹션 총점 + 검증 상태 ■ 인터랙션: - 입력 변경 시 실시간 재계산 (oninput 이벤트) - 현재 해당 구간 셀에 하이라이트 배경색 - 에러: 빨간 테두리 + 툴팁 - 경고: 노란 뱃지 - 점수 셀 hover 시 breakdown 툴팁 ("D초과 → 0.55 × 20 = 11.0") - "행 추가" / "행 삭제" 버튼 (섹션당 최대 6행) ■ 스타일 (엑셀 원본 색상): - 입력 셀: #E2EFDA (연한 초록) - 실적 셀: #DDEBF7 (연한 파랑) - 구간값 셀: #9BC2E6 (파랑) - S등급 하이라이트: #002060 텍스트 (진한 파랑) - 에러: #FF0000 테두리 - 경고: #FDE9D9 배경 ■ 두 가지 모드: 1) 빈 템플릿 모드: 빈 행으로 시작 2) 회귀 테스트 모드: 🧪 버튼 → 아래 값 자동 로드 → pass/fail 표시 ■ 회귀 테스트 로드 데이터: [ { name:"설비 가동률 증대", weight:20, unit:"건수", dir:"down", target:0, floor:1.25, actual:2 }, { name:"자체 정비 비용 절감", weight:30, unit:"건수", dir:"up", target:2, floor:0, actual:2 }, { name:"년간 투자 계획 이행률",weight:20, unit:"%", dir:"up", target:25, floor:20, actual:30 }, { name:"건조 배기 가스비 절감",weight:20, unit:"백만원",dir:"up", target:5.75, floor:5.5, actual:0 }, { name:"선제적 법규 준수", weight:10, unit:"점", dir:"up", target:0, floor:0, actual:0 } ]
Phase 7 — 회귀 테스트 자동 검증
엑셀과 정확히 같은 결과가 나오는지 자동 검증하는 테스트를 만들어라. ■ 정확한 기대값 (엑셀에서 추출한 실제 값): ┌───┬─────────────────────┬──────┬──────┬──────┬────────────┬────────────┬──────┐ │ # │ KPI │ S │ A │ B │ C │ D │ 득점율│ 점수 │ ├───┼─────────────────────┼──────┼──────┼──────┼────────────┼──────┼──────┼──────┤ │ 1 │ 설비 가동률 증대 │ 0 │ 0 │ 0 │ 1 │ 1.25 │ 0.55 │ 11.0 │ │ 2 │ 자체 정비 비용 절감 │ 3 │ 2 │ 1 │ 0 │ 0 │ 1.00 │ 30.0 │ │ 3 │ 년간 투자 계획 이행률│ 27.5 │ 25 │ 23.333…│21.667… │ 20 │ 1.10 │ 22.0 │ │ 4 │ 건조 배기 가스비 절감│6.325 │ 5.75 │ 5.667…│ 5.583… │ 5.5 │ 0.55 │ 11.0 │ │ 5 │ 선제적 법규 준수 │ 0 │ 0 │ 0 │ 0 │ 0 │ 1.10 │ 11.0 │ └───┴─────────────────────┴──────┴──────┴──────┴────────────┴──────┴──────┴──────┘ 총점: 85.0 ■ 구간 판정 기대값: 1) 설비중단건수: actual=2 > D=1.25(하향) → below(D초과) → Y열=0.55 2) 자체정비비용: actual=2 = A=2(상향) → A구간 → V열=1.00 3) 투자이행률: actual=30 >= S=27.5(상향) → S구간 → U열=1.10 4) 배기가스비: actual=0 < D=5.5(상향) → below → Y열=0.55 5) 법규준수: actual=0 <= S=0(상향) → S구간 → U열=1.10 ■ 달성률 기대값: 1) 목표=0, down → null (zero_target) — 엑셀: 빈칸 2) 2/2 = 1.0 — 엑셀: 1.0 (=100%) 3) 30/25 = 1.2 — 엑셀: 1.2 (=120%) 4) 0/5.75 = 0.0 — 엑셀: 0.0 (=0%) 5) 목표=0, up → null (zero_target) — 엑셀: 빈칸 ■ 비교 허용 오차: 소수점 6자리 이내 일치 (1e-6) ■ 엣지케이스 추가 테스트: EDGE-1: target=0, down, actual=0 → 0<=0 → S등급 → 1.10 EDGE-2: target=0, up, actual=0 → 0>=0 → S등급 → 1.10 EDGE-3: actual=null → scoreRate=0, status="no_input" EDGE-4: floor=target (구간폭=0) → 0/0 방지, A 또는 D로 직행 EDGE-5: 비중합계 ≠ 100 → warning EDGE-6: 소수점 실적 + 정수형 KPI → warning (구간은 정수 처리) ■ 테스트 UI: "🧪 회귀 테스트" 버튼 → 테스트 데이터 로드 → 각 항목 pass/fail → 기대값 vs 실제값 diff (불일치 시 빨간색) → 전체 pass 시 "✅ 엑셀 호환성 검증 통과"
