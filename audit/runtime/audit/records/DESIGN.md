# 조도 기록 화면 디자인 계약

## 1. 분위기와 시그니처

조도 기록 화면은 장식보다 연도·팀·분기 자료의 빠른 식별을 우선하는 정돈된 문서 색인이다. 밝은 중성 배경, 얇은 경계선, 촘촘한 행 구조를 유지하고 불필요한 화면 제어는 노출하지 않는다.

## 2. 색상

- `--audit-lux-page: #f3f4f6` — 화면 바탕
- `--audit-lux-surface: #ffffff` — 창과 자료 행
- `--audit-lux-surface-muted: #f9fafb` — 헤더와 호버 상태
- `--audit-lux-foreground: #111827` — 제목과 핵심 정보
- `--audit-lux-foreground-muted: #374151` — 보조 정보와 아이콘
- `--audit-lux-border-strong: #9ca3af` — 창과 연도 구획
- `--audit-lux-border: #d1d5db` — 행과 미리보기 구획
- `--audit-lux-focus: #0d67d6` — 키보드 포커스 강조
- 위험·성공 색상은 기존 조도 입력 검증 상태에서만 사용한다.

## 3. 타이포그래피

- 기본 글꼴: `"Noto Sans KR", system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
- 화면 제목: `20px / 900 / 1.2 / 0`
- 연도 제목: `13px / 900 / 1.2 / 0`
- 팀명과 주요 제어: `12.5px / 800~900 / 1.3 / 0`
- 보조 정보: `12px / 700~800 / 1.35 / 0`

## 4. 간격

- 기본 단위는 `2px`이다.
- 간격 눈금: `2, 4, 6, 8, 10, 12, 16, 18px`.
- 창 외곽 여백은 `12px`, 헤더 여백은 세로 `10px`·가로 `12px`, 색인 행 내부 여백은 `7px`을 유지한다.
- 기존 표 밀도를 보존하며 새 장식 여백을 추가하지 않는다.

## 5. 컴포넌트

- 조도 창 헤더는 전구 아이콘과 `조도` 제목만 표시한다.
- 조도 창 헤더에는 전체화면 버튼이나 빈 액션 컨테이너를 렌더링하지 않는다.
- 연도 구획은 강한 경계선으로, 팀별 자료는 한 줄 경계선으로 나눈다.
- 팀 목록은 `1팀 1파트`, `1팀 2파트`, `2팀`, `3팀` 순서로 연속 표시하며, 조도 화면에서는 팀명에 유틸리티 항목명을 덧붙이지 않는다.
- 팀 셀은 설비 이력과 같은 팀색, 10% 팀색 배경, 24px 팀별 SVG 아이콘을 사용한다. 1팀은 건조, 2팀은 포장, 3팀은 액상, 공무환경팀은 공구 아이콘으로 표시한다.
- 기입·원본 보기·첨부 교체·분리 보기 등 자료 업무 제어는 현재 위치와 동작을 유지한다.
- 작업 이력과 설비 이력의 전체화면 제어는 이 계약의 대상이 아니다.

## 6. 모션

- 호버 피드백은 배경·경계색의 `160ms ease` 전환만 사용한다.
- 레이아웃 크기나 위치를 움직이는 애니메이션은 추가하지 않는다.
- `prefers-reduced-motion`에서는 비필수 전환을 즉시 적용한다.

## 7. 깊이

- 깊이는 그림자보다 배경 명도 차와 `1px` 경계선으로 표현한다.
- 조도 파일 색인 창과 행에는 새 그림자나 글로우를 추가하지 않는다.
