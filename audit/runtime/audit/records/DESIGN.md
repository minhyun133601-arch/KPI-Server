# 조도 기록 화면 디자인 계약

## 1. 화면 흐름

조도 기록은 연도와 팀을 먼저 고른 뒤 해당 팀의 누적 측정 자료를 확인하는 화면이다. 한 장의 측정표에 분기 기록을 계속 누적하므로 뒤 분기 자료를 등록하면 그 분기까지 완료로 표시한다. 선택한 팀 하나에 집중하고, 완료 범위와 누적 자료의 출처를 글자로 분명하게 표시한다. 밝은 중성색과 얇은 경계선을 사용하며 완료·미완료 구분에만 색을 조금 사용한다. 팀색, 팀 아이콘, 장식용 배지와 그림자는 추가하지 않는다.

- 첫 화면에는 `연도`, `팀` 선택과 선택 안내만 표시한다. 팀을 선택하기 전에는 다른 팀의 자료나 진행 상황을 나열하지 않는다.
- 팀을 선택하면 `2026년 / 1팀 1파트 조도 측정`처럼 현재 범위를 제목으로 표시한다.
- 완료 요약, 완료 범위 설정, 1~4분기 선택, 선택한 분기의 자료 순서로 읽는다.
- 별도의 전구 아이콘과 큰 창 헤더를 표시하지 않는다. 연도·팀 선택 옆에는 화면을 식별할 수 있는 작은 `조도` 제목을 유지한다. 화면 영역은 `조도 측정 자료`라는 접근성 이름으로 구분한다.

## 2. 정보와 상태

- 완료 범위는 `2분기까지 완료`, `2 / 4분기`와 가느다란 진행 막대로 함께 표시한다.
- 같은 연도·팀의 가장 뒤 분기에 등록한 자료를 누적 측정표로 사용한다. 예를 들어 3분기 자료를 등록하면 1·2분기 파일이 없어도 1~3분기를 자동으로 완료 처리하며, 이 분기를 선택하면 모두 해당 3분기 누적 자료를 표시한다.
- 완료 범위 설정은 해당 연도·팀에만 적용하며 저장 결과를 가까운 상태 메시지로 알린다. 등록한 누적 자료로 자동 완료된 범위보다 낮게 설정할 수 없다.
- 분기 버튼에는 분기명, `완료`·`미완료`·`예정`, 누적 자료 유무를 표시한다. 이전 분기를 선택해도 `3분기 누적 자료 · 1~3분기 포함`처럼 실제 자료의 등록 분기와 포함 범위를 표시한다.
- 선택한 분기는 진한 경계선과 `aria-pressed`로 구분한다. 완료 상태에는 옅은 녹색 바탕과 녹색 글자, 미완료에는 황갈색 상태 글자를 사용한다. 상태 문구와 완료 글자의 굵기를 함께 사용해 색상만으로 전달하지 않는다. 선택하거나 호버해도 완료 색상과 선택 경계선을 유지한다.
- 선택할 수 없는 미래 분기는 비활성 상태와 `예정` 문구로 표시한다.
- 자료가 없으면 짧은 안내와 `자료 등록` 제어를 표시한다. 자료가 있으면 파일명과 누적 자료 출처, `원본 열기`, `다운로드`, `자료 교체` 제어를 제공한다.
- 이전 분기에서 누적 자료를 확인하는 중에 `자료 교체`를 누르면 화면에 표시된 출처 분기의 원본을 교체한다.
- 자료 조회와 자동 완료 범위는 연도·팀을 넘지 않는다. 이전에 등록한 파일은 보존하고, 누적 표시를 위해 과거 분기에 파일을 복사하거나 새 첨부를 만들지 않는다.
- 팀 목록은 `1팀 1파트`, `1팀 2파트`, `2팀`, `3팀` 순서의 기존 이름을 사용한다. 팀명에 유틸리티 항목명을 덧붙이지 않는다.

## 3. 색상과 깊이

색상 변수는 `.audit-lux-shell.is-team-view` 안에서 정의한다.

- `--audit-lux-page: #ffffff` — 화면 바탕
- `--audit-lux-surface: #ffffff` — 본문과 제어
- `--audit-lux-surface-muted: #fafafa` — 자료 바탕과 호버 상태
- `--audit-lux-foreground: #262626` — 제목, 기본 본문과 선택 경계선
- `--audit-lux-foreground-muted: #737373` — 보조 문구
- `--audit-lux-border: #e5e5e5` — 구획과 기본 경계선
- `--audit-lux-border-strong: #a3a3a3` — 입력 제어 경계선
- `--audit-lux-focus: #404040` — 키보드 포커스
- `--audit-lux-complete: #3f6e50` — 완료 상태, 완료 요약과 진행 막대
- `--audit-lux-complete-surface: #f2f7f3` — 완료 분기의 옅은 바탕
- `--audit-lux-incomplete: #946b26` — 미완료 상태와 미완료 요약

주요 자료 등록 제어는 어두운 중성 배경으로 표시한다. 완료·미완료와 오류 메시지 외에는 중성색을 사용하고 예정 분기도 중성색을 유지한다. 큰 색상 면이나 장식용 배지를 추가하지 않는다. 깊이는 여백, 배경 명도 차와 `1px` 경계선으로 표현한다.

## 4. 글자와 간격

- 기본 글꼴: `"Noto Sans KR", system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
- 선택 영역의 `조도` 제목 `18px`, 선택한 팀 제목 `20px`, 완료 요약 `19px`, 자료 제목 `16px`
- 선택 제어와 본문 안내 `13~14px`, 파일명과 보조 상태 `12px`
- 일반 안내는 보통 굵기, 제목과 완료 상태만 `600~700`을 사용한다.
- 본문은 너비 제한 없이 콘텐츠 영역 전체를 사용한다. 바깥 여백과 창 테두리는 없애고 본문 가로 여백은 `24px`를 기준으로 한다. 화면 높이는 공통 상단바를 제외한 영역을 채운다.
- 선택 영역, 완료 요약, 분기 목록, 자료 사이에는 `14~20px`의 간격을 둔다. 분기 제어는 `88px` 높이를 기준으로 한다.
- 입력 선택 제어 높이는 `44px`, 보조 제어는 `38px`를 기준으로 한다.

## 5. 자료 미리보기와 작은 화면

- 한 번에 선택한 분기의 자료 하나를 크게 표시한다. 기존 전체 팀·전체 연도 썸네일 색인은 이 화면에 표시하지 않는다.
- 이미지는 비율을 유지해 `600px` 높이 영역에서 확인하며, PDF는 `620px` 높이 프레임을 사용한다. 원본을 열어 세부 내용을 확인할 수 있다.
- `760px` 이하에서는 본문 여백을 `16px`로 줄이고 분기를 `2 × 2`로 배치하며 자료 제어가 다음 줄로 자연스럽게 이어지게 한다.
- `480px` 이하에서는 본문 가로 여백을 `12px`로 줄이고 연도와 팀 선택을 각각 한 줄로 배치한다. 긴 파일명과 제목은 줄바꿈하며 가로 스크롤을 만들지 않는다.
- 작은 화면의 미리보기 높이는 이미지 `420px`, PDF `500px`를 기준으로 한다.

## 6. 접근성과 구현 범위

- 연도·팀과 완료 범위에는 연결된 레이블을 제공한다. 분기 버튼은 그룹으로 묶고 선택 상태를 전달한다.
- 키보드 포커스에는 `2px` 외곽선을 사용한다. 저장 결과는 상태 메시지로 전달한다.
- 화면 진입 애니메이션과 호버 전환 효과를 사용하지 않는다. 선택·완료·포커스 상태는 정적으로 즉시 표시한다.
- 전용 스타일은 `audit-lux-team.css`에서 `.audit-lux-shell.is-team-view` 아래로 제한하고 `audit.css`에서 가져온다.
- 기존 조도 입력 화면, 공통 팀 표시 스타일, 작업 이력과 설비 이력의 디자인은 이 계약의 대상이 아니다.
